Training Info
How Training Works:
  1. Scans all images in the data_img folder
  2. Extracts facial features from each image
  3. Creates a unique model for each student
  4. Saves the trained model as clf.xml
  5. Creates ID mapping for recognition
Requirements:
  • At least 10 images per student
  • Clear, well-lit face images
  • Various angles and expressions
Note: Training may take several minutes depending on the number of images.
Training Data

Training images are stored in the data_img folder. Each image should be named as student.[ID].[number].jpg
